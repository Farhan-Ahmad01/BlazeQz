# BlazeQz

BlazeQz is a topic-based quiz application that helps users test and improve their knowledge across various computer science categories. Each quiz generates a new set of questions, provides instant scoring, and shows performance analysis. Offline mode is supported through local caching.

## Features

- Topic-based quizzes from multiple computer science categories  
- 10 new questions in every quiz attempt  
- Immediate scoring and performance analysis  
- Offline support using Room Database (SQLite)  
- Option to report incorrect or unclear questions  
- Fast and scalable backend with seamless data flow  

## My Role
